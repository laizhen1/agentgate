# AgentGate：可核验的 STAR 微调表述

以下数字来自实际执行的 run-001；三个训练种子全部报告，未挑选最佳种子。
“领域测试集”必须注明为 AI 辅助构建的合成数据，而不是用户日志或独立人工标注数据。

## 简历版本

**威胁检测与领域微调：**针对采购 Agent 场景中正常安全讨论与恶意指令易混淆的问题，构建 480 条合成对照样本（60 个场景族），按场景族隔离训练、验证和测试数据；基于 PyTorch / Hugging Face 对 DeBERTa-v3 注入检测器进行全参数微调，对比 TF-IDF、原始检测器及 3 个训练种子，并仅在验证集选择阈值。在 96 条领域留出样本上，原始检测器召回率为 50.00%，微调后三种子的平均召回率为 95.83%，平均误报率为 4.86%；另使用 1,001 条公开样本评估泛化限制。

建议紧接一条结果限制：**通过固定阈值对照识别泛化代价：deepset F1 从 57.98% 降至 50.75%，保留模型为实验性检测器，并记录错误切片与部署限制。**

不要把这一句改成“真实业务准确率”或“拦截了多少实际攻击”。检测器评估没有运行 Agent 工具执行，也没有测量真实业务损失。

## 面试时展开 STAR

**S — Situation：**采购 Agent 会读取用户请求、供应商文档和工具返回文本。直接使用已有提示词注入检测器可能把正常的安全术语讨论当作攻击，或者漏掉领域中的权限绕过指令，因此需要评估领域适配是否有帮助。

**T — Task：**在控制正常请求误报的条件下，改善领域注入识别，并验证改善是否能迁移到公开诊断集；构建可复现的证据，而非只展示训练脚本。

**A — Action：**

- 用 AI 辅助编写 60 个成对场景族，每族包含正常请求和恶意指令；每条消息生成 4 个上下文变体，共 480 条。承认同族样本相关且未经独立人工复标。
- 按类别和场景族固定划分 288 / 96 / 96 条训练、验证、测试样本，同族变体不跨集合；保存数据、模型和代码哈希。
- 从 Protect AI 已有注入检测 checkpoint 开始，对 184,423,682 个参数继续监督微调，而非从零训练，也没有使用 LoRA。
- 使用交叉熵二分类训练路径、AdamW、学习率 2e-5、3 epochs、microbatch 1、梯度累积 8、BF16 和梯度检查点；512-token 窗口、64-token 重叠，动态 padding。
- 对比 TF-IDF + Logistic Regression、原始检测器和微调种子 42 / 43 / 44；最终轮次提前固定，未通过测试集挑选 checkpoint。
- 仅在验证集上以经验误报率不超过 5% 为约束选阈值，并额外报告共同 0.5 阈值，区分参数适配与阈值变化。

**R — Result：**

| 测试集 | 指标 | 原始检测器 | 微调三种子均值 | 微调种子范围 |
|---|---|---:|---:|---:|
| 领域合成留出集（96 条） | Recall | 50.00% | 95.83% | 95.83%–95.83% |
| 领域合成留出集（96 条） | FPR | 6.25% | 4.86% | 2.08%–6.25% |
| deepset（662 条） | F1 | 33.02% | 51.58% | 50.14%–52.92% |
| deepset（662 条） | Recall | 19.77% | 34.85% | 33.46%–36.12% |
| NotInject（339 条正常输入） | FPR | 14.75% | 12.29% | 12.09%–12.68% |

以上均使用各模型在领域验证集上选定的阈值。公开测试集不参与阈值选择；5% 是验证集选择约束，不是测试集承诺。完整 fixed-0.5 对照见 REPORT.md。

**预先规定的共同 0.5 阈值对照：**领域召回率从 79.17% 变为 95.83%，领域误报率从 31.25% 变为 3.47%；NotInject 误报率从 42.77% 变为 11.60%。但 deepset F1 从 57.98% 降至 50.75%，召回率从 41.44% 降至 34.09%。这些结果应一起解读，不能只挑选有利阈值。

**简单基线同样重要：**验证集选阈值后，TF-IDF 的领域 F1 为 95.65%，略高于微调三种子的平均 95.51%。这个合成集没有证明神经模型在 F1 上优于简单方法。

## 必须保留的边界

- 领域留出集只有 12 个场景族，不应把 96 条变体当成 96 个完全独立场景。配对场景族 bootstrap 区间保存在 aggregate.json。
- 公开数据可能与原始模型的上游训练数据重叠，无法证明其对原始模型完全未见；它们没有用于本次领域适配。
- NotInject 全部为正常输入，只测误报，不测攻击召回率。
- 如果公开集指标下降，应明确说明领域适配的泛化代价。不要只展示领域集的提升。
- 训练使用本地 RTX 3060 Laptop GPU；Colab notebook 是复现入口，未声称在 Colab 完成训练。
- 保存了全部三份 checkpoint，并验证 seed 42 能被现有检测服务加载；没有自动替换应用默认模型。
